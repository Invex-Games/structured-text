Renders typed expressions (Expr) and Templates to GitHub Actions expression syntax: infix operators (==, &&, !), single-quoted string literals, and ${{ … }} around expressions embedded in text.

Remarks

Portable references render as context paths: secrets as secrets.NAME, variables as vars.NAME, inputs as inputs.NAME, matrix values as matrix.NAME, job outputs as needs.JOB.outputs.NAME, step outputs as steps.STEP.outputs.NAME and job results as needs.JOB.result. Result literals render as 'success', 'failure', 'cancelled' and 'skipped'.
