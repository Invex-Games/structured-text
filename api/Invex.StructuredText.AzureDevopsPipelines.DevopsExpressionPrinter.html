Renders typed expressions (Expr) and Templates to Azure DevOps syntax. Operators are functions (and(...), or(...), not(...), eq(...), …) and status checks are succeeded(), failed(), canceled() and always().

Remarks

Inside a Template, secrets, variables, matrix values and step outputs are written as macros ($(name)). Expressions that depend on other jobs (job outputs, job results) or contain a DevopsRuntimeExpr are runtime expressions ($[ … ]), and everything else is a template expression (${{ … }}).

Combinations Azure DevOps can't evaluate throw System.NotSupportedException: a runtime expression combined with text or other expressions (Azure DevOps only evaluates one that is the whole value), an input read in a runtime expression or condition (parameters only exist at compile time), and a secret, matrix value or step output inside a compound compile-time expression (they only exist at run time). Bind the value to a variable and reference it with Variable(string) instead.

Inside an expression, secrets, variables and matrix values are variables['name'], inputs are parameters.name, job outputs are dependencies.JOB.outputs['STEP.NAME'] and job results are dependencies.JOB.result.
