Inheritance

Template

Remarks

Build one from a plain string (literal text), from any Expr (an embedded expression), or from an interpolated string whose holes are expressions: $"{workflow}-{branch}". A printer wraps each embedded expression in the platform's expression delimiters, so no manual evaluate or concatenate step is needed.

Templates are immutable once built.
