Class Tex

Invex.StructuredText.Expressions

Invex.StructuredText.dll

The starting point for writing expressions. Everything that creates an expression from scratch lives here: references (Secret(string), JobOutput(string, string, string?), …), status checks (Success(), …), functions (All(params IEnumerable<BoolExpr>), Format(StringExpr, params IEnumerable<Expr>), …) and the escape hatch Raw(string). Platform packages add their own members, such as Tex.GitHub for the GitHub Actions contexts.

public static class Tex
Inheritance
object
Tex

Remarks

Once you have an expression, its own members do the rest: Eq, Contains, StartsWith, the &&, || and ! operators, and indexers for JSON values. Add using static Invex.StructuredText.Expressions.Tex; to drop the Tex. prefix.
