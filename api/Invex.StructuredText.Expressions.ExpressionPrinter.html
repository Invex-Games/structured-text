Remarks

The base class handles operator precedence (adding parentheses only where needed), literal quoting and escaping, casts, raw text and context paths. Platforms override the members that differ: how operators and functions are spelled, how ReferenceExpr nodes and ResultLiterals are written, and how an embedded expression is delimited inside a Template.

Nodes the printer doesn't recognise cause a System.NotSupportedException.
