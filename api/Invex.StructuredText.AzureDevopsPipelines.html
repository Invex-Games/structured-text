Namespace Invex.StructuredText.AzureDevopsPipelines

Classes

DevopsAgentVariables

Agent.* predefined variables.

DevopsBuildVariables

Build.* predefined variables.

DevopsContexts

Azure DevOps predefined variables and run-time expressions, reached through Tex.DevOps. Each variable is a Variable(string) reference: $(Build.BuildId) in a template and variables['Build.BuildId'] in a condition.

DevopsExpressionPrinter

Renders typed expressions (Expr) and Templates to Azure DevOps syntax. Operators are functions (and(...), or(...), not(...), eq(...), …) and status checks are succeeded(), failed(), canceled() and always().

DevopsPipelineWriter

Serializes a DevopsPipeline model to Azure Pipelines YAML. Expressions embedded in the model are rendered with DevopsExpressionPrinter.

DevopsRuntimeExpr

Marks an expression to be evaluated at run time. Embedded in a Template, it renders as \([ … ]</code> instead of the compile-time <code>\){{ … }}. Create one with Tex.DevOps.Runtime(…).

DevopsSystemVariables

System.* predefined variables.

TexDevopsExtensions

Adds the Azure DevOps predefined variables and run-time expressions to Tex.
