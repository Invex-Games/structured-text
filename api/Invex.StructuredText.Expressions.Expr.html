The base type of the typed expression tree. Every node derives from one of the four result-typed roots: BoolExpr, StringExpr, NumberExpr or JsonExpr.

Remarks

Nodes are immutable records. They are rendered to platform syntax by an ExpressionPrinter; ToString() uses a neutral infix rendering intended for debugging and test output.
